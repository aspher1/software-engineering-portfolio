# Track A staff review: strongest objections

1. **RLock and internal locking may add latency on the critical exit path.** Every manage cycle now acquires the state lock in `_roll_day`; prune and save acquire it again. The real liveness hazard, stale network I/O under that lock, remains. A slower manager could miss a fast exit. **Response:** The extra acquisitions are local and short; no network was added to these helpers. The old unlocked prune provably lost a cap append, which is a direct risk-control failure. The full suite, including manage-cycle tests, passes. We leave the stale fetch issue explicit in the audit and recommend measuring it before changing commit sequencing.

2. **Falling back to empty state on valid but malformed JSON can orphan an existing paper position.** A damaged file with recoverable fields could deserve repair rather than reset. **Response:** This follows the requested fallback policy and logs `STATE LOAD FAILED` with the reason. It does not rewrite the corrupt source during construction. The tradeoff is real: a later operator restart could proceed without previously recorded positions. An operator should inspect the source first; this mission did not restart the bot. A migration/recovery tool would be a separate change with its own tests.

3. **Making `to_f` reject all non-finite values changes a shared conversion helper and might suppress a marginal signal that previously entered.** DexScreener also now rejects non-finite price change, volume, and liquidity; stricter filtering changes observed trade counts. **Response:** NaN comparisons demonstrably bypassed minimum gain and could emit NaN into JSON; NaN liquidity crashed GT rounding. Infinite values also cannot represent trustworthy observed market data. Golden tests show finite conversions and normal GT/DS signal fields are unchanged. The stricter cases are exactly malformed inputs, and the rug guard/risk caps are untouched.

Test harness note: six fixture assignments in four existing test files now create `RLock`, matching `Trader.__init__`; those fixtures construct `Trader.__new__` and had installed non-reentrant locks. The first full-suite attempt hung on the first such fixture; with fixture locks aligned to the runtime contract, all 436 tests pass.
